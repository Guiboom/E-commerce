Condições de conclusão
Com base no projeto base crud_php(https://github.com/danielbaumannbr/crud_php), crie uma nova aplicação web que contenha os seguintes recursos:

Autenticação de Usuários: Sistema seguro de login para acesso restrito.
Gerenciamento de Produtos: Cadastro de produtos com suporte a upload de fotos.
(opcional) Sistema de Pedidos: Funcionalidade que permite aos usuários autenticados realizarem pedidos selecionando os produtos desejados.

Vamos começar juntos por aqui: https://app.brmodeloweb.com/publicview/6ab2aa49dfd394f31d45470a
